<h1 align="center">OmniPlugins</h1>

<p align="center">The official plugin repository for <b>OmniStream</b>.</p>

---

## Add this repository

In OmniStream, open **Settings → Plugin Manager → Add repository** and paste:

```
https://raw.githubusercontent.com/TamerAli-0/omniplugins/builds/repo.json
```

Then pick a plugin from the list and tap **Install**. Plugins update in place — when a
newer version lands here, the app offers it on the Updates tab.

## Available plugins

| Plugin | Type | Language | Content |
|---|---|---|---|
| Cineby | Video | English | Movies, TV series — multi-server playback with built-in subtitles |

## How it works

Every plugin is a self-contained `.omni` package. OmniStream ships with no knowledge of
any source: install a plugin and the source appears, remove it and the source is gone.
Nothing here is bundled into the app itself.

This branch holds documentation only. The published packages and the repository index
live on the [`builds`](https://github.com/TamerAli-0/omniplugins/tree/builds) branch.
